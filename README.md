# Responsive Engineering Portfolio

A responsive personal portfolio website built using HTML, CSS, and JavaScript.

The website is designed to showcase my engineering background, technical skills, projects, education, and professional experience in a modern and interactive format.

## Features

- Responsive design for desktop, tablet, and mobile
- Dark and light mode
- Animated typing effect
- Scroll reveal animations
- Project filtering
- Skills and tools section
- Education and experience timeline
- Contact section
- Mobile navigation menu

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- VS Code
- Git and GitHub
